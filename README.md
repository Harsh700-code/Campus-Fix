# Campus Fix – A Smart Campus Issue Reporting System

Campus Fix is a full-stack web application designed to simplify the process of reporting, tracking, and managing campus-related issues.

The platform allows students to report problems such as damaged infrastructure, electrical faults, sanitation issues, and other campus maintenance concerns. Administrators can manage reported issues, assign them to the appropriate departments, and track their progress until resolution.

The project aims to improve campus maintenance efficiency through a centralized and transparent issue management system.

## 🚀 Features

- **Issue Reporting:** Students can submit campus issues with descriptions, photos, categories, and locations.
- **Student Dashboard:** Track reported issues and monitor their current status.
- **Admin Dashboard:** Manage reported issues, assign responsibilities, and update issue statuses.
- **Issue Tracking:** Follow the complete issue lifecycle:
  `Pending → Assigned → In Progress → Resolved`
- **REST API Integration:** Communication between the React frontend and Flask backend.
- **AI-Assisted Triage (Planned):** Suggest issue categories and priorities using AI and help identify recurring campus problems.
